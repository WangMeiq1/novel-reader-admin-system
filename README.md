网文小说读者后台管理系统
基于JavaEE + Vue开发的课程综合项目。

📖项目简介
本系统是面向网文小说平台的读者后台管理系统，实现基础的后台数据管理功能。

🛠技术栈
- 后端：Java、SpringBoot、MyBatis
- 前端：Vue3、Vite、Axios
- 数据库：MySQL

📁项目结构
- `demo`：后端代码
- `front/web`：前端Vue项目
- `score_management.sql`：数据库脚本

 🚀运行说明
1. 在MySQL中执行 `score_management.sql`，导入数据库
2. 修改后端数据库连接配置
3. 启动后端服务
4. 进入front/web目录，执行：

   npm install
   npm run dev
